iOS 6 Archive Repo

Preserving legacy software for jailbroken iOS devices.

About

Welcome to the iOS 6 Archive Repo.

This repository is dedicated to preserving legacy jailbreak packages and software for older iOS devices, especially packages compatible with iOS 6.

The goal is to keep useful software available even after the original repositories or distribution channels have disappeared.

Compatibility

iOS 6.0 iOS 6.1 iOS 6.1.3 iOS 6.1.6 iphoneos-arm

Add to Cydia

Add this URL to Cydia:

https://himazin-github.github.io/iOS6ArchiveRepo/

Archive Policy

This repository focuses on software preservation. Packages are intended to be redistributed only when redistribution is permitted by the applicable license or by the copyright holder.

If you are the copyright holder of a package hosted here and believe it should not be redistributed, please contact the repository maintainer.
